# E-commerce Sales Analytics Dashboard

Interactive business intelligence dashboard developed with Streamlit to monitor and optimize the performance of an independent e-commerce activity selling posters and digital wallpapers.

## Overview

This project centralizes sales, profit, tax, commission, and operational expense data into a single analytics interface with dynamic visualizations and KPI tracking.

The dashboard was built to support data-driven decision making across:
- Sales performance
- Product profitability
- Tax estimation
- Expense tracking
- Revenue monitoring
- Operational management

## Features

- Interactive KPI dashboard
- Monthly and daily profit analysis
- Product-level profitability tracking
- Top-performing artwork analysis
- Tax and commission estimation
- Expense categorization and monitoring
- Revenue comparison and breakdowns
- Dynamic filters and drill-down analysis
- Automated data processing pipeline

## Tech Stack

- Python
- Streamlit

- Data Visualization
- Business Intelligence
